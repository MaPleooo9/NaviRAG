## 怎么填

在文件末尾照下面的格式追加就行。**一条只需要 6–8 行**，别写长篇大论。

```markdown
## 玛莲妮亚 | Malenia, Blade of Miquella

### 冻伤壶 + 仿身泪滴无脑流
- 无脑度: 4
- 等级: 120
- 需要: 冻伤壶, 仿身泪滴的骨灰
- 步骤:
  1. 进雾门前召唤仿身泪滴
  2. 站在她背后丢冻伤壶，触发冻伤后出血伤害翻倍
  3. 二阶段开场立刻后撤，避开腐败之花
- 风险: 水鸟乱舞起手仍可能秒杀，看到起跳必须后滚
- 验证: 是
```

### 字段说明

| 字段 | 怎么填 | 为什么需要 |
|---|---|---|
| `## 标题 \| English` | 中文名 **\|** 英文官方名 | 英文用来关联 L1 wiki 页面 |
| `### 打法名` | 起个好认的名字 | 展示用 |
| **无脑度** | 1–5，见下表 | 回答"给我最无脑的"时排序用 |
| **等级** | 建议等级数字 | 回答"我 60 级能逃吗"时过滤 |
| **需要** | 逗号分隔：道具/骨灰/武器 | 回答"不用骨灰怎么逃"时排除 |
| **步骤** | 编号列表，3–6 步 | 检索内容主体 |
| **风险** | 一句话翻车点 | 回答"有没有稳一点的" |
| **验证** | 是 / 否 | 亲自打过的优先 |

### 无脑度标准（很重要，统一标准检索才准）

| 值 | 含义 |
|---|---|
| 1 | 仍需正常操作，只是思路更优 |
| 2 | 简化不少，但要躲关键招 |
| 3 | 很无脑，站桩输出为主 |
| 4 | 几乎不用操作，靠召唤物/道具 |
| 5 | 完全无脑，boss 打不到你 |

## 写什么最容易出彩

按这个优先级挑，比随机写更有价值：

1. **卡地形 / 卡门** —— wiki 绝对不写，纯社区智慧
2. **特定道具的组合技** —— 冻伤壶、腐败吐息、投掷匕首
3. **召唤流** —— 仿身泪滴、无头骑士、腐败野狗
4. **属性克制** —— 某 boss 怕冻伤/出血/睡眠
5. **装备逃课** —— 大蛇狩猎枪、特定战灰

**别写**：正常打法流程、数值表、剧情（这些 L1 wiki 全有，写了是重复劳动）

## 大树守卫 | Tree Sentinel

### 灵马远程风筝
- 无脑度: 3
- 等级: 30
- 需要: 灵马, 弓或投掷物
- 步骤:
  1. 开局直接上马往回跑，拉出他的追击范围
  2. 回头射一箭，等他冲锋接近
  3. 骑马绕圈，反复回头射击
  4. 血量低时他自己会掉下悬崖或脱战
- 风险: 悬崖边容易自己掉下去；被盾牌弹反会硬直
- 验证: 否

## 拉塔恩 | Starscourge Radahn

### 全员 NPC + 腐败磨血流
- 无脑度: 4
- 等级: 70
- 需要: 腐败吐息或腐败箭
- 步骤:
  1. 进场先往左右跑，激活战场上的所有金色召唤印记
  2. 自己不主动靠近，保持在弓箭射程边缘
  3. 等他锁定 NPC 后，远程上一次腐败
  4. 腐败生效后骑马兜圈等跳阶段

## 玛莲妮亚 | Malenia, Blade of Miquella

### 冰霜踏地压制流
- **无脑度**: 4
- **等级**: 120
- **需要**: 双持重型武器, 战灰“冰霜踏地”, 仿生泪滴骨灰+8以上
- **步骤**:
  1. 前往卡利亚城寨正门，在三姊妹塔附近，篝火左边尽头的水池里，击杀隐身甲壳虫，获得战灰“冰霜踏地”,
  2. 前往“仪式镇”奥缇娜，点燃4个火（上3个下1个，高楼上的火在梯子背面），通过解密进入女武神区域,

- **需要**: 高伤害的远程武器（如弓、法术或祷告）

  1. 进入战场后，先丢一个火球（或任意远程攻击）触发Boss的仇恨,
  2. 从地图旁边的小口绕上较高的石台,
  3. 在石台上耐心等待Boss起飞并飞到石台上方（即Boss会爬上石台）,
  4. 当Boss飞上石台后，迅速下坡，绕到Boss的背后,
  5. 此时Boss会持续尝试爬墙（不会转身），玩家可放心在背后用远程武器输出,
  6. 注意不要靠近Boss的尾巴，否则会触发转身攻击；由于Boss血量极高，需确保远程武器伤害足够,
- **风险**: 走位不慎靠近尾巴会遭反击；Boss可能提前转身；远程武器伤害不足会拖长战斗增加风险,
- **验证**: 否
