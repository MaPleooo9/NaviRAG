# L3 常规打法层（人工整理）

> 这一层放**正常打法**——不卡 bug、不利用地形、不作弊，靠操作和机制理解打赢。
>
> L2（逃课）和 L3（常规）是两种完全不同的需求：
> 有人第一次通关想学真本事，有人二周目只想赶紧过去。
> 混在一层里，问「怎么逃课」会召回归常规打法，问「怎么打」又会召回归逃课——两边都不对。

## 怎么填

一条 8-10 行，复制模板改即可。**难度**是 L3 的核心字段（L2 是无脑度）：

```markdown
## 中文名 | English Name

### 打法名（流派）
- **难度**: 3
- **等级**: 100
- **需要**: 武器/道具/战灰，多个用逗号分隔
- **核心思路**: 一句话讲清这套打法成立的原因
- **步骤**:
  1. 第一步
  2. 第二步
- **翻车点**: 最容易死在哪
- **验证**: 否
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| 难度 | 是 | 1-5，越高越吃操作。1=有手就行，5=需要反复练 |
| 等级 | 是 | 建议等级，写「无」视为无门槛 |
| 需要 | 否 | 关键道具/战灰，没有就不填 |
| 核心思路 | 是 | **L3 独有**。逃课靠道具，常规靠理解，这句是精华 |
| 步骤 | 是 | 编号列表，每条一句话 |
| 翻车点 | 否 | 最容易被这套打法坑死的地方 |
| 验证 | 是 | 自己打过写「是」，AI 起草/听说写「否」 |

## 和 L2 的区别

|  | L2 逃课层 | L3 常规层 |
|---|---|---|
| 核心字段 | 无脑度（越低越难） | 难度（越高越难） |
| 成立依据 | 道具 / 地形 / 机制漏洞 | 招式理解 / 翻滚时机 |
| 关键提示 | 风险（会不会失效） | 核心思路（为什么这样打） |
| 典型提问 | 「怎么逃课」「最无脑」 | 「怎么打」「招式怎么躲」 |

## “米凯拉的锋刃”玛莲妮亚 | Malenia, Blade of Miquella

### 轻装单挑流（翻滚抓后摇）
- **难度**: 5
- **等级**: 120
- **需要**: 轻装（负重低于 70%），单手武器或武士刀，可选：猎犬步法战灰
- **核心思路**: 她真正致命的只有水鸟乱舞，其余招式全都有明确后摇。整套打法就是「看清起手 → 侧向翻滚穿过 → 砍一刀立刻退」，绝不贪第二刀。
- **步骤**:
  1. 保持中距离引她出招，先看清楚起手动作再动，不要预判
  2. 一阶段的突刺和横扫，统一向她的左侧（你的右手边）翻滚穿过
  3. 落地后只砍一刀，立刻后撤拉开距离，等下一招
  4. 水鸟乱舞按三拍躲：第一波向前翻滚贴身、第二波原地不动、第三波向后翻滚
  5. 她蓄力长矛突进时提前侧滚，落地硬直很长，可以安全打两刀
  6. 二阶段开场必定放腐败之花，直接向后跑出范围，别贪这一刀
  7. 二阶段的影分身是虚招，等真身落地再动，乱翻滚只会白给
  8. 她血量低于三成会频繁转连击，此时只防守，等收招硬直再补刀
- **翻车点**: 贪第二刀必被水鸟乱舞抓；她有吸血，拖越久越难；二阶段腐败积累极快，务必带腐败苔藓药
- **验证**: 是

## “碎星将军”拉塔恩 | Starscourge Radahn

### 召唤群殴流（设计本意打法）
- **难度**: 3
- **等级**: 70
- **需要**: 灵马，可选：腐败吐息或毒雾
- **核心思路**: 这场战斗本来就设计成群殴——场内 NPC 无限重生，你的任务是补召唤、拉扯仇恨、绕背补刀，而不是单挑。
- **步骤**:
  1. 开场立刻上马向右前方跑，避开他的第一波箭雨
  2. 沿途捡起地上的召唤记号，把能召的 NPC 全部召出来
  3. 有 NPC 顶住后，骑马绕到他背后，下马砍两刀立刻上马撤离
  4. NPC 阵亡就继续补召唤，这是全场最重要的事，比输出优先级高
  5. 他进入二阶段会拔剑，范围重力技起手明显，上马全速跑开
  6. 天上陨石阶段所有 NPC 会死光，继续补召唤，别贪输出
- **翻车点**: 只骑马不打输出会拖到他狂暴；二阶段重力波范围极大，马速不够会被秒；NPC 死光时贴脸必被连
- **验证**: 是

## “恶兆王”蒙葛特 | Morgott, the Omen King

### 近战抓硬直流
- **难度**: 3
- **等级**: 80
- **需要**: 任意武器，可选：中盾配黄金格挡
- **核心思路**: 他的连招收招硬直很长，而且大部分物理攻击可以弹反。节奏是「防两招 → 抓硬直 → 打一刀」。
- **步骤**:
  1. 一阶段保持中距离，等他跳劈或冲刺，翻滚穿过后打一刀就退
  2. 他的长刀突刺可以弹反，弹反两次即可处决，处决伤害很可观
  3. 他举武器蓄力砸地时硬直很长，可以安全打两刀
  4. 二阶段他会变红并使用咒血技能，场地同时变小，改为贴身绕圈
  5. 地面血刃直线推进，向后翻滚两次，不要停在直线上
  6. 他举杖召唤黄金长矛时横向移动躲开，长矛会追踪落地
- **翻车点**: 二阶段咒血伤害高，血少容易被秒；在他背后停留太久会吃尾扫
- **验证**: 是

## “黑剑”玛利喀斯 | Maliketh, the Black Blade

### 贴身压制流
- **难度**: 4
- **等级**: 110
- **需要**: 轻装，可选：猎犬步法战灰
- **核心思路**: 一阶段的野兽祭司很好打，难点全在二阶段的命定之死——它会削减血量上限并持续掉血，所以必须贴身速战，越拖越死。
- **步骤**:
  1. 一阶段他扔飞刀时别直线跑，横向绕动靠近，打两刀就退
  2. 一阶段地面猛砸可以跳起来躲，落地有大硬直
  3. 二阶段开场他会跳起放黑剑，向前翻滚穿过剑气，别往后退
  4. 二阶段核心是贴身——他的连招在贴身距离下更容易整段落空
  5. 他举剑发光的三连斩，第一刀后立刻连翻两次，第三下有长硬直可以输出
  6. 被命定之死命中立刻退开，等减血上限的 debuff 结束再上
  7. 他血量最后两成会连续跳劈，保持翻滚不要贪刀
- **翻车点**: 命定之死叠到三层基本必死；远离他时会放追踪剑气，比贴身更危险；负重过高翻滚不动就没法打
- **验证**: 是

## “血王”蒙格 | Mohg, Lord of Blood

### 近战绕背流
- **难度**: 4
- **等级**: 100
- **需要**: 可选：无垢金针（米莉森支线奖励，可中断二阶段血咒）
- **核心思路**: 他的招式大多朝正前方，右后方是相对安全区。真正的难点是二阶段的三次血焰咒会强制扣血，没有免疫手段就是硬亏三管血。
- **步骤**:
  1. 一阶段的长矛横扫范围很大，统一向他的左侧翻滚穿过
  2. 他向地面砸矛会有小范围爆炸，翻滚躲开后有硬直可以补刀
  3. 全程尽量贴住他的右后方，很多招式在这个角度直接打空
  4. 二阶段他会念咒三次、屏幕变红，此时用无垢金针中断，没有就提前拉开距离硬吃
  5. 三阶段他会长翅飞起，落地是大范围血焰，向后翻滚两次
  6. 他血量低于四成会连续突刺，保持翻滚节奏，等收招再打
- **翻车点**: 二阶段三次血咒必扣大量血，不带免疫手段容易直接崩盘；空中落地技范围极大，贴脸躲不掉
- **验证**: 是

## 英雄石像鬼 | Valiant Gargoyle

### 集火减员流（速杀一只回归一对一）
- **难度**: 3
- **等级**: 80
- **需要**: 可选：出血或冻伤类武器（石像鬼对异常状态积累响应快）
- **核心思路**: 这场本质是人数战——第一只血量过半时第二只会从天而降加入，硬扛二对一必被夹死。胜负手是趁两怪的交接混乱期集火速杀一只，把战斗拉回熟悉的一对一节奏。
- **步骤**:
  1. 一阶段单只：它的锤击和吐息后摇都很长，绕到侧面打两刀就退
  2. 它起飞旋转突进或俯冲时向后拉开，别原地贪刀
  3. 第一只血量过半时第二只从天而降，立刻远离落点区域
  4. 借场中石柱分隔两只的仇恨视线，挑血量更少的那只集中输出
  5. 速杀一只后回到一对一，按一阶段的节奏绕侧输出
  6. 双打期间宁可空刀不输出，也不要站在两只的连线中间
- **翻车点**: 被两只前后夹击基本必死；第二只落地砸击范围大，太早贴上去会被波及；拖得太久耗不过两只的轮番进攻
- **验证**: 是

## 穿刺者米德拉 | Midra, Lord of Frenzied Flame

### 贴身速攻流（抓瞬移硬直）
- **难度**: 2
- **等级**: 100
- **需要**: 无强制要求，可选：韧性高的重武器方便出处决
- **核心思路**: 他是 DLC 里少有的「血薄速攻」对象——血量低、韧性差，拖久了狂焰覆盖全场反而越打越难。全程贴身压制、抓他瞬移后的硬直滚雪球，速战速决就是最好的防守。
- **步骤**:
  1. 一阶段他瞬移换位后有小硬直，立刻贴上打两刀
  2. 他的狂焰爆发抬手前摇明显，看到起手向后翻滚一次即可
  3. 全程别主动拉开距离——拉远了他反而进入安全输出形态
  4. 二阶段他体型变大，多数攻击变成飞行道具，横向翻滚可以整段躲过
  5. 二阶段他蓄力大技时冲脸输出，要么打断要么抢下大量伤害
  6. 他韧性很低，连续重击或跳劈能频繁打出处决
- **翻车点**: 站远了会吃满飞行道具弹幕；二阶段蓄力技范围极大，翻滚一次躲不掉；狂焰异常积累极快，中两下就崩盘
- **验证**: 是

## 恶兆妖鬼玛尔基特 | Margit, the Fell Omen

### 弹反惩罚流
- **难度**: 3
- **等级**: 30
- **需要**: 中盾（弹反战技），可选：连续弹反护符
- **核心思路**: 他的招式前摇非常明显且部分可以弹反，是官方设计的「教学关」——目的就是逼玩家学会弹反和抓后摇，而不是硬拼数值。
- **步骤**:
  1. 保持中距离，他举杖横扫或连段结束后有长硬直，上前打一刀就退
  2. 他的杖击突刺可以弹反，弹反两次左右就能处决
  3. 他连挥三下的第三下后摇最长，是全场最安全的输出窗口
  4. 他跳起扔圣光飞刀时横向翻滚，落点别站
  5. 血量过半进入二阶段会掏出大锤，锤子砸地是延迟拍，等一下再翻滚
- **翻车点**: 他很多连段是延迟拍，按普通节奏翻滚会被第二下打中；贪两刀就会被补尾刀
- **验证**: 否

## 接肢葛瑞克 | Godrick the Grafted

### 绕侧打腿流
- **难度**: 2
- **等级**: 35
- **需要**: 任意武器，可选：召唤骨灰分摊仇恨
- **核心思路**: 他动作大开大合、后摇极长，绕到侧面几乎打空；难点只在二阶段的龙头，掌握了「喷火后必有大硬直」的规律就是木桩战。
- **步骤**:
  1. 一阶段他的斧头横扫后绕侧面打两刀，正面千万别站
  2. 他接肢旋风斩范围大，看到起手直接后撤两次
  3. 二阶段龙头喷火是纵向扫，向他的左侧贴身绕
  4. 龙息扫完是大硬直，可以安全打三刀
  5. 他抓取技前会单手高举，看到就拉开距离
- **翻车点**: 二阶段龙息范围误判是最常见死因；召唤骨灰时他大概率立刻放旋风斩，召完先躲再输出
- **验证**: 否

## 飞龙亚基尔 | Agheel, the Flying Dragon

### 骑马环绕流
- **难度**: 2
- **等级**: 30
- **需要**: 灵马，远程武器（弓/法术）更舒服
- **核心思路**: 这条龙的第一招大俯冲覆盖率极高，硬站地面必死；骑马环绕让它大部分喷火落空，落地窗口期再下马输出腿。
- **步骤**:
  1. 开场它在湖中央落地，先上马，别急着靠近
  2. 骑马绕大圈，等它俯冲或喷火结束再接近
  3. 它喷火时全速横跑，火焰是直线扫不是追踪
  4. 落地间隙下马打后腿两三刀，立刻上马
  5. 血量四成左右它会飞起二次俯冲，看影子躲落点
- **翻车点**: 开场站位太近会被第一口火直接秒；下马贪第三刀大概率被甩尾
- **验证**: 否

## 大树守卫 | Tree Sentinel

### 下马绕腿流
- **难度**: 2
- **等级**: 25
- **需要**: 可选：灵马（拉扯用）
- **核心思路**: 骑马对冲它等于送死——它的矛比你的马长。正确解法是引它冲刺落空后下马，贴着马腿打：马腿处它大部分攻击都打不到。
- **步骤**:
  1. 骑马引它冲刺，横向让开，冲过头就是输出窗口
  2. 下马贴身绕马腿打，它的矛劈砍在高处，贴腿很难吃满
  3. 它举盾冲撞时向后翻滚两次，别横向躲
  4. 它举矛蓄力突刺范围极远，提前斜向翻滚穿过
  5. 打出处决后绕到马头侧补处决技
- **翻车点**: 贪刀被马蹄踩中连击；它掉头速度比看起来快，绕圈别固定方向
- **验证**: 否

## 满月女王蕾娜菈 | Rennala, Queen of the Full Moon

### 召唤清场流（一阶段）/ 贴身压制流（二阶段）
- **难度**: 2
- **等级**: 45
- **需要**: 可选：狼类骨灰（一阶段清场神器）
- **核心思路**: 这场是机制战不是数值战——一阶段只要找对「举蛋的学童」砸三波就过；真正的战斗在二阶段，而她法师身板极脆，贴身她就废了一半。
- **步骤**:
  1. 一阶段召出狼骨灰，狼会自动清小怪
  2. 找到头顶发光举金蛋的学童，冲过去砸碎，三次进二阶段
  3. 二阶段开场她悬浮施法，冲近打断第一波
  4. 贴身绕后输出，她的近战很弱，贴脸她只能翻滚逃
  5. 她飘空放落雷时前摇很长，保持移动即可
  6. 月亮陨石砸地时向她方向翻滚穿过（范围边缘反而危险）
- **翻车点**: 一阶段乱打无发光的小怪纯属浪费；二阶段站远了吃满法术弹幕，比近身危险得多
- **验证**: 否

## 亵渎君王拉卡德 | Rykard, Lord of Blasphemy

### 蛇猎长矛流
- **难度**: 1
- **等级**: 40
- **需要**: 蛇猎长矛（Boss 房门口拾取，专属武器，必拿）
- **核心思路**: 官方设计的机制战——不拿蛇猎长矛伤害减免九成，拿了就是站桩射击游戏。整场战斗就是「远程战技点他，躲两招岩浆」。
- **步骤**:
  1. 进房前务必捡起门口的蛇猎长矛
  2. 全程保持中距离，用长矛战技远程点射，命中伤害很稳
  3. 他张嘴吐岩浆弹时横向跑，弹道落点有明显预警
  4. 大范围岩浆喷发后摇很长，是最佳输出期
  5. 二阶段他换形态，套路不变，贴脸反而要吃抓投，保持距离
- **翻车点**: 忘拿专属武器是唯一翻车方式；贪刀冲脸会被抓投秒
- **验证**: 否

## 熔炉骑士 | Crucible Knight

### 耐心弹反流
- **难度**: 4
- **等级**: 60
- **需要**: 中盾（弹反），轻装更好
- **核心思路**: 他是全游戏「教学式」硬仗——出手慢、伤害高、韧性硬，拼速度必输，拼耐心必赢。整场就是「他出招 → 你精确翻滚或弹反 → 打一刀」，节奏放慢。
