# L3 常规打法层（人工整理）

> 这一层放**正常打法**——不卡 bug、不利用地形、不作弊，靠操作和机制理解打赢。
>
> L2（逃课）和 L3（常规）是两种完全不同的需求：
> 有人第一次通关想学真本事，有人二周目只想赶紧过去。
> 混在一层里，问「怎么逃课」会召回归常规打法，问「怎么打」又会召回归逃课——两边都不对。

## 怎么填

一条 8-10 行，复制模板改即可。**难度**是 L3 的核心字段（L2 是无脑度）：

```markdown
## 中文名 | English Name

### 打法名（流派）
- **难度**: 3
- **等级**: 100
- **需要**: 武器/道具/战灰，多个用逗号分隔
- **核心思路**: 一句话讲清这套打法成立的原因
- **步骤**:
  1. 第一步
  2. 第二步
- **翻车点**: 最容易死在哪
- **验证**: 否
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| 难度 | 是 | 1-5，越高越吃操作。1=有手就行，5=需要反复练 |
| 等级 | 是 | 建议等级，写「无」视为无门槛 |
| 需要 | 否 | 关键道具/战灰，没有就不填 |
| 核心思路 | 是 | **L3 独有**。逃课靠道具，常规靠理解，这句是精华 |
| 步骤 | 是 | 编号列表，每条一句话 |
| 翻车点 | 否 | 最容易被这套打法坑死的地方 |
| 验证 | 是 | 自己打过写「是」，AI 起草/听说写「否」 |

## 和 L2 的区别

|  | L2 逃课层 | L3 常规层 |
|---|---|---|
| 核心字段 | 无脑度（越低越难） | 难度（越高越难） |
| 成立依据 | 道具 / 地形 / 机制漏洞 | 招式理解 / 翻滚时机 |
| 关键提示 | 风险（会不会失效） | 核心思路（为什么这样打） |
| 典型提问 | 「怎么逃课」「最无脑」 | 「怎么打」「招式怎么躲」 |

## “米凯拉的锋刃”玛莲妮亚 | Malenia, Blade of Miquella

### 轻装单挑流（翻滚抓后摇）
- **难度**: 5
- **等级**: 120
- **需要**: 轻装（负重低于 70%），单手武器或武士刀，可选：猎犬步法战灰
- **核心思路**: 她真正致命的只有水鸟乱舞，其余招式全都有明确后摇。整套打法就是「看清起手 → 侧向翻滚穿过 → 砍一刀立刻退」，绝不贪第二刀。
- **步骤**:
  1. 保持中距离引她出招，先看清楚起手动作再动，不要预判
  2. 一阶段的突刺和横扫，统一向她的左侧（你的右手边）翻滚穿过
  3. 落地后只砍一刀，立刻后撤拉开距离，等下一招
  4. 水鸟乱舞按三拍躲：第一波向前翻滚贴身、第二波原地不动、第三波向后翻滚
  5. 她蓄力长矛突进时提前侧滚，落地硬直很长，可以安全打两刀
  6. 二阶段开场必定放腐败之花，直接向后跑出范围，别贪这一刀
  7. 二阶段的影分身是虚招，等真身落地再动，乱翻滚只会白给
  8. 她血量低于三成会频繁转连击，此时只防守，等收招硬直再补刀
- **翻车点**: 贪第二刀必被水鸟乱舞抓；她有吸血，拖越久越难；二阶段腐败积累极快，务必带腐败苔藓药
- **验证**: 否

## “碎星将军”拉塔恩 | Starscourge Radahn

### 召唤群殴流（设计本意打法）
- **难度**: 3
- **等级**: 70
- **需要**: 灵马，可选：腐败吐息或毒雾
- **核心思路**: 这场战斗本来就设计成群殴——场内 NPC 无限重生，你的任务是补召唤、拉扯仇恨、绕背补刀，而不是单挑。
- **步骤**:
  1. 开场立刻上马向右前方跑，避开他的第一波箭雨
  2. 沿途捡起地上的召唤记号，把能召的 NPC 全部召出来
  3. 有 NPC 顶住后，骑马绕到他背后，下马砍两刀立刻上马撤离
  4. NPC 阵亡就继续补召唤，这是全场最重要的事，比输出优先级高
  5. 他进入二阶段会拔剑，范围重力技起手明显，上马全速跑开
  6. 天上陨石阶段所有 NPC 会死光，继续补召唤，别贪输出
- **翻车点**: 只骑马不打输出会拖到他狂暴；二阶段重力波范围极大，马速不够会被秒；NPC 死光时贴脸必被连
- **验证**: 否

## “恶兆王”蒙葛特 | Morgott, the Omen King

### 近战抓硬直流
- **难度**: 3
- **等级**: 80
- **需要**: 任意武器，可选：中盾配黄金格挡
- **核心思路**: 他的连招收招硬直很长，而且大部分物理攻击可以弹反。节奏是「防两招 → 抓硬直 → 打一刀」。
- **步骤**:
  1. 一阶段保持中距离，等他跳劈或冲刺，翻滚穿过后打一刀就退
  2. 他的长刀突刺可以弹反，弹反两次即可处决，处决伤害很可观
  3. 他举武器蓄力砸地时硬直很长，可以安全打两刀
  4. 二阶段他会变红并使用咒血技能，场地同时变小，改为贴身绕圈
  5. 地面血刃直线推进，向后翻滚两次，不要停在直线上
  6. 他举杖召唤黄金长矛时横向移动躲开，长矛会追踪落地
- **翻车点**: 二阶段咒血伤害高，血少容易被秒；在他背后停留太久会吃尾扫
- **验证**: 否

## “黑剑”玛利喀斯 | Maliketh, the Black Blade

### 贴身压制流
- **难度**: 4
- **等级**: 110
- **需要**: 轻装，可选：猎犬步法战灰
- **核心思路**: 一阶段的野兽祭司很好打，难点全在二阶段的命定之死——它会削减血量上限并持续掉血，所以必须贴身速战，越拖越死。
- **步骤**:
  1. 一阶段他扔飞刀时别直线跑，横向绕动靠近，打两刀就退
  2. 一阶段地面猛砸可以跳起来躲，落地有大硬直
  3. 二阶段开场他会跳起放黑剑，向前翻滚穿过剑气，别往后退
  4. 二阶段核心是贴身——他的连招在贴身距离下更容易整段落空
  5. 他举剑发光的三连斩，第一刀后立刻连翻两次，第三下有长硬直可以输出
  6. 被命定之死命中立刻退开，等减血上限的 debuff 结束再上
  7. 他血量最后两成会连续跳劈，保持翻滚不要贪刀
- **翻车点**: 命定之死叠到三层基本必死；远离他时会放追踪剑气，比贴身更危险；负重过高翻滚不动就没法打
- **验证**: 否

## “血王”蒙格 | Mohg, Lord of Blood

### 近战绕背流
- **难度**: 4
- **等级**: 100
- **需要**: 可选：无垢金针（米莉森支线奖励，可中断二阶段血咒）
- **核心思路**: 他的招式大多朝正前方，右后方是相对安全区。真正的难点是二阶段的三次血焰咒会强制扣血，没有免疫手段就是硬亏三管血。
- **步骤**:
  1. 一阶段的长矛横扫范围很大，统一向他的左侧翻滚穿过
  2. 他向地面砸矛会有小范围爆炸，翻滚躲开后有硬直可以补刀
  3. 全程尽量贴住他的右后方，很多招式在这个角度直接打空
  4. 二阶段他会念咒三次、屏幕变红，此时用无垢金针中断，没有就提前拉开距离硬吃
  5. 三阶段他会长翅飞起，落地是大范围血焰，向后翻滚两次
  6. 他血量低于四成会连续突刺，保持翻滚节奏，等收招再打
- **翻车点**: 二阶段三次血咒必扣大量血，不带免疫手段容易直接崩盘；空中落地技范围极大，贴脸躲不掉
- **验证**: 否
