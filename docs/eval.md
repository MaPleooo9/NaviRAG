# 检索层评估报告

评估集：85 条人工标注问法，分 8 组：逃课意图 / 常规意图 / 口语俗称 / 否定表达 / 知识问答 / 描述提问 / 等级过滤 / 无脑度意图

判定标准：Top-K 中出现「期望层 + 期望目标」才算命中。


两套判定口径并列呈现（以前只有宽松口径，容易被误读）：

- **宽松**：L2/L3 要求 `target` 与期望规范名完全相等；L1 无 `target` 字段，降级为「标题包含期望名」——同名词页面（如「玛莲妮亚的追忆」）也算对。

- **严格**：L1 升级为「页面主实体就是它本人」（去称号、去括号后缀后全等），L2/L3 不变。两组数字差得越多，说明虚高部分越大。

## 归因拆分：线上方案的成绩里，规则和向量各占多少

统一在「期望 L2/L3」的 78 条子集上比较——L1 条目没有 `target` 字段，纯规则无法定位到具体 wiki 页面，混在全集上比不公平。

| 方案 | Hit@1 | Hit@5 | MRR |
|---|---|---|---|
| A 单路纯向量 | 7.7% | 15.4% | 0.105 |
| C +分层加权 | 11.5% | 23.1% | 0.152 |
| E 纯实体规则(无向量) | 60.3% | 84.6% | 0.707 |
| D−enhance(关增强) | 91.0% | 93.6% | 0.920 |
| D +实体命中(线上) | 91.0% | 93.6% | 0.916 |

- **一次向量都不查**的纯实体规则，已经能把正确答案捞进候选框（Hit@5 84.6%），但排不准首位（Hit@1 只有 60.3%）；向量+分层把前者的问题补上，Hit@1 拉到 91.0%。所以是**规则主召回、向量主精排**，二者互补而非替代——单独拆开谁都不够看（纯向量只有 11.5%）。
- 顺带了结一个旧疑点：B 已说明「术语增强在**单路**检索里有害」（MRR 0.159 → 0.146）；但在**分层体系**里它的影响落在噪声级——Hit@1 与 MRR 和关掉时完全一致（90.6% / 0.915 vs 90.6% / 0.915），Hit@5 各赢一半（全量 94.1% vs 92.9%，L2/L3 子集 93.6% vs 93.6%）。即：增强在完整链路里既没被证明有用、也没造成明显损害——比起保留一个无法证明价值的模块，更该评估直接关掉它以简化链路。
